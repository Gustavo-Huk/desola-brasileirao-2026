# De Sola × Brasileirão 2026

Painel independente que compara os 103 palpites da simulação com os resultados reais.

- Site: https://desola-brasileirao-2026.vercel.app/
- Rodada de teste fictícia: https://desola-brasileirao-2026.vercel.app/?demo=rodada29
- Fonte dos resultados: https://valorfinal.com.br/brasileirao/dados-abertos

O projeto é HTML, CSS e JavaScript estáticos. A Vercel publica a branch `main`; mudanças nesses arquivos geram um novo deploy. Os resultados dos jogos são consultados pelo navegador ao abrir a página ou pelo botão de atualização, sem exigir um commit.
